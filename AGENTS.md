# Instrucciones del proyecto

Las skills de este repositorio están en `.agents/skills/`. Leer la skill correspondiente antes de modificar el área indicada:

- Frontend, componentes, estilos y UX: [lapredigital-frontend](.agents/skills/lapredigital-frontend/SKILL.md).
- API, lógica de negocio y persistencia: [lapredigital-backend](.agents/skills/lapredigital-backend/SKILL.md).
- Cambios que abarcan ambas áreas: aplicar las dos skills.

Las rutas del código se resuelven desde la raíz de este repositorio. Mantener `.editorconfig` y `.prettierrc.json` como configuración de formato y consultar `README.md` y `server/README.md` para ejecución y alcance.
